# 校园监控插件说明

`plugins/` 下有四个只对**上海交通大学**有意义的插件。它们的认证方式各不相同，
这也是它们最容易踩坑的地方。本文把差异和坑集中写出来。

> 不是交大用户？直接删掉这四个 `.py` 和对应的 `.json` 即可，其余功能完全不受影响。

| 插件 | 监控对象 | 认证方式 | 凭证寿命 |
|---|---|---|---|
| `jwc.py` | 教务处通知（7 个栏目） | **无需认证**（公开静态网页） | — |
| `canvas.py` | Canvas：公告/作业/课件/成绩 | Personal Access Token（或 `canvas_session` cookie） | 最长 120 天 |
| `aihaoke.py` | 知途好课：课程任务 | HttpOnly cookie `haoke-token` 的值（JWT） | 约 1~2 周 |
| `sjtu_academic.py` | 第二课堂：活动报名 | 非 HttpOnly cookie `IMPSA-Token`（JWT） | **恰好 24 小时** |

## 共同的反直觉之处

### 1. HTTP 状态码恒为 200

知途好课和第二课堂的错误码都在**响应体的 `code` 字段**里，HTTP 状态码永远是 200。
未登录时也是 `HTTP 200 + code:401`。**判错只能看 body，不能看状态码。**

### 2. 每个请求都要带 `requestId`

这两个平台的接口都需要在请求体里带一个 uuid 形式的 `requestId`，漏了会报
`code 500 请求标识不能为空`。如果你手写请求测试，记得带上——插件的 `_post`
封装已经处理了这件事。

### 3. "认证接口能通"不代表凭证有效

知途好课的 `queryCurrentUserInfo` **只验签、不认证**：即使会话已经死了，
它照样返回 200。判活必须打**业务接口**（如 `listMyClass`）。
第二课堂同理，要真拉一次活动列表。

### 4. 时间字段有哨兵值

知途好课的 `endTime` 用 `9999-12-31 23:59:59` 表示"无截止时间"，
`beginTime` 用 `1900-01-01` 表示"无开始时间"。不过滤会推出"还剩 290 万年"。

第二课堂的 `registration_time` 可能是 `[null, null]`（收藏了一个还没安排报名的活动），
必须跳过而不是拿 None 去算提醒时刻。

### 5. 端点是 POST，不是 GET（知途好课）

知途好课的**所有业务接口都是 POST**，查询参数放在 body 里。没有 GET 版本。

## 自动同步凭证（Tampermonkey）

好课和第二课堂的凭证会过期，手动复制很烦，所以这两个插件各自在**本机回环地址**
上开了一个小接口（默认端口 `37219` / `37218`），配合浏览器用户脚本自动接收新 token：

1. 给机器人发 `#好课同步` 或 `#二课同步`，它会给你安装地址和步骤。
2. 装好 Tampermonkey 脚本后，只要你正常用浏览器访问那个网站，token 就会自动同步过来。

安全上有三层防护：

- 只绑定 `127.0.0.1`，局域网内的其它机器碰不到；
- 需要 `X-Sync-Key` 请求头（密钥首次使用时自动生成）；
- CORS 只放行对应站点来源，且要求 JSON 正文。

> **踩过的坑**：Chrome 的 Private Network Access 策略要求预检响应带上
> `Access-Control-Allow-Private-Network: true`，否则公网页面访问本机的请求
> **会被浏览器静默拦掉**——服务端看起来一切正常，只有客户端发不出去。

## 第二课堂的 token 只有 24 小时

这是这个插件最大的可用性缺陷，且平台**没有刷新令牌机制**。插件会在过期前 3 小时
私聊提醒你，收到提醒后：

1. 浏览器登录 <https://activity.sjtu.edu.cn> → F12 → Console，执行：

   ```js
   copy(document.cookie.split(';').map(s=>s.trim()).find(s=>s.startsWith('IMPSA-Token=')).slice(12))
   ```

2. 把剪贴板内容私聊发给机器人：`#二课token 粘贴的内容`

机器人会先**实测**（解 JWT 看过没过期 + 真拉一次活动列表）确认可用才写盘。
`#二课token` 只在私聊生效；发到群里会被撤回并提示你重新取一个。
